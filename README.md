# イヌ式市場|半自動化UI

**ChatGPT手動コピペ支援版**です。各工程の専用ChatGPTチャットを固定し、そのチャット冒頭にプロンプト全文をあらかじめ設置して運用します。通常作業ではプロンプト全文を毎回貼らず、UIから工程チャットを開き、必要な入力文だけをコピーし、ChatGPT出力を貼り戻して保存します。

## この版で行わないこと

- ChatGPT Webの自動操作は行いません。
- Playwrightは使いません。
- OpenAI APIは使いません。
- Xやnoteへ直接投稿しません。
- 画像生成は行いません。
- ChatGPTへの貼り付け、送信、出力コピーはユーザーが手動で行います。

## 新しい運用方針

1. プロンプト管理画面で工程0〜6のプロンプト全文を確認・編集します。
2. 各工程のChatGPTチャット/プロジェクトを作成し、チャット冒頭に対応プロンプト全文を貼っておきます。
3. 設定画面で工程ごとの固定チャットURLを登録します。
4. 通常作業では、各工程画面の主ボタンを使います。
   - 工程チャットを開く
   - 入力文をコピー
   - 出力を貼り戻す
   - 保存して次へ
5. 初期化文コピーやプロンプト全文コピーは、プロンプト修正・チャット作り直し用の補助機能としてプロンプト管理画面/設定画面に残しています。

## 起動方法

```bash
npm install
npm run dev -- --host 0.0.0.0
```

起動時に以下のような表示が出ます。

```text
イヌ式市場|半自動化UI is running.
Mode: manual copy-paste support

PC:
http://localhost:5173

Smartphone:
http://192.168.x.x:5173
```

スマホから操作する場合は、PCと同じWi-Fiに接続し、起動ログに出た `http://192.168.x.x:5173` へアクセスしてください。`npm run build` で静的Webアプリとしてビルドできます。ブラウザ単独利用時は `localStorage` にもデータを保持し、別端末への移行はJSONエクスポート/インポートで行います。

## 基本ワークフロー

1. 設定画面で工程チャットURLを登録する。
2. 工程0で「買い目判定チャットを開く」を押す。
3. 工程0の実行コードボタンを押してコピーし、ChatGPTへ貼る。
4. ChatGPTから返った3行判定をUIへ貼り戻す。
5. 「コードブロックだけ抽出」を必要に応じて押す。
6. 「解析して新規バッチ作成」または「既存バッチに追加」を押す。
7. 工程1〜6で対象銘柄の「工程チャットを開く」「入力文をコピー」を使う。
8. ChatGPT出力を貼り戻し、「貼り戻し保存」「保存して次の銘柄へ」「保存して次工程へ」で保存する。

## 工程0〜6

| 工程 | 固定チャット | 入力文 | 出力 | 保存先 |
|---|---|---|---|---|
| 工程0：買い目判定 | 買い目判定チャット | 実行コード | 買い目判定v3の3行コード | `rawJudgmentText` |
| 工程1：X記事作成 | X記事作成チャット | `rawJudgmentText` のみ | X記事本文 | `xArticle` |
| 工程2：英語Xポスト作成 | 英語Xポスト作成チャット | `rawJudgmentText` のみ | 海外投資家向け英語Xポスト | `overseasXPost` |
| 工程3：note記事作成 | note記事作成チャット | `rawJudgmentText` のみ | note記事本文 | `noteArticle` |
| 工程4：日本語Xポスト作成 | 日本語Xポスト作成チャット | `noteArticle` のみ | 日本語X本ポスト | `japaneseXPostMain` |
| 工程5：note画像指示書 | note画像指示書チャット | `noteArticle` のみ | noteヘッダー画像生成用英語指示書 | `noteImagePrompt` |
| 工程6：X画像指示書 | X画像指示書チャット | `noteArticle` のみ | X用正方形画像生成用英語指示書 | `xImagePrompt` |

工程1〜3の入力文にはプロンプト全文を混ぜません。工程4〜6も `noteArticle` のみをコピーします。設定で「入力文末尾にUI貼り戻し用出力ルールを付ける」をオンにできますが、デフォルトはオフです。

## 工程チャットURL設定

設定画面で以下の固定チャットURLを保存できます。

- `step0ChatUrl`: イヌ式市場|買い目判定
- `step1ChatUrl`: イヌ式市場|X記事作成
- `step2ChatUrl`: イヌ式市場|X英語ポスト作成
- `step3ChatUrl`: イヌ式市場|note記事作成
- `step4ChatUrl`: イヌ式市場|X日本語ポスト作成
- `step5ChatUrl`: イヌ式市場|note画像指示書
- `step6ChatUrl`: イヌ式市場|X画像指示書

URLが未設定の工程で「工程チャットを開く」を押すと、次の警告を表示します。

```text
この工程のチャットURLが未設定です。
設定画面で、プロンプトを設置済みのChatGPTチャットURLを登録してください。
```

## プロンプト管理

プロンプト管理画面では、工程0〜6のプロンプト全文を保管・編集・保存・コピーできます。

- 工程0：買い目判定プロンプト
- 工程1：X記事作成プロンプト
- 工程2：X英語ポスト作成プロンプト
- 工程3：note記事作成プロンプト
- 工程4：X日本語ポスト作成プロンプト
- 工程5：note画像指示書プロンプト
- 工程6：X画像指示書プロンプト

各プロンプトには以下の補助コピーがあります。

- このプロンプトをコピー
- 初期化文をコピー
- UI貼り戻し用出力ルール付きでコピー

画面上にも「このプロンプトを工程チャット冒頭に貼ってください」と表示しています。

## 貼り戻しとコードブロック抽出

工程0の3行判定取り込み欄と、各銘柄カードの出力貼り戻し欄に「コードブロックだけ抽出」ボタンがあります。ChatGPTが ``` で囲んだ出力を返した場合でも、中身だけを抽出して保存できます。

## JSONエクスポート/インポート

設定画面またはプロンプト管理画面から、以下をJSONでエクスポート/インポートできます。

- `batches`
- `settings`
- `templates` / `promptTemplates`
- `favoriteCommands`
- project/chat URLs
- postStatus相当の工程別保存状態（各銘柄の `statusByStep`）

インポート時は「既存データに追加」または「既存データを上書き」を選べます。同じ `batchId` は追加モードではインポートJSON側の内容で反映されます。

## 保存場所

開発サーバー利用時は以下のローカルJSONにも保存します。

- `data/batches.json`
- `data/settings.json`
- `data/promptTemplates.json`

ブラウザ側にも `localStorage` でミラー保存し、サーバーAPIが利用できない静的起動時の第一段階の端末単独利用に対応します。PCとスマホのリアルタイム同期は行いません。

## API

主なAPIは以下です。

- `GET /api/health`
- `GET /api/batches`
- `GET /api/batches/:batchId`
- `POST /api/batches/manual-import`
- `POST /api/batches/create-from-command`
- `POST /api/stocks/:stockId/save`
- `GET /api/templates`
- `POST /api/templates/save`
- `GET /api/settings`
- `POST /api/settings/save`
- `POST /api/export`
- `POST /api/import`
- `POST /api/build-copy-text`

`POST /api/run` は互換性のため残していますが、ChatGPT自動実行は無効である旨のエラーを返します。
