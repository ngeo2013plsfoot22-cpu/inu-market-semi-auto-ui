# イヌ式市場|半自動化UI

スマホを操作盤として使い、PC上のPlaywrightランナーがChatGPT Web画面を操作して、イヌ式市場の投資コンテンツ生成作業を半自動化するMVPです。OpenAI APIは使いません。Xやnoteへ直接投稿せず、画像生成そのものも行いません。生成物をローカルJSONへ保存し、ユーザーが確認して手動で貼り付けます。

## セットアップ

```bash
npm install
npx playwright install
npm run dev
```

起動すると以下のようなURLが表示されます。

```text
イヌ式市場|半自動化UI is running.
PC:
http://localhost:5173
Smartphone:
http://192.168.x.x:5173
```

スマホはPCと同じWi-Fiに接続し、表示された `Smartphone` URLへアクセスしてください。ローカルIPは macOS/Linux なら `ipconfig getifaddr en0`、Windows なら `ipconfig`、Linux なら `ip addr` でも確認できます。

> 注意: このアプリはPC上のブラウザを自動操作するため、GitHub Pages単体では動作しません。PCで `npm run dev` を起動し、ChatGPTへログイン済みの状態で使ってください。

## ChatGPTログインとプロジェクトURL

PC側のPlaywrightブラウザでChatGPTログインが必要です。設定画面で工程別のChatGPTプロジェクトURLを登録してください。工程別URLが空の場合は `defaultProjectUrl` を使います。どちらも空なら実行時にエラーになります。

### 専用Chromeプロファイルでの初回ログイン

Playwrightランナーはデフォルトで `browserMode: chrome` を使い、Playwright同梱の Chrome Testing / bundled Chromium ではなく、通常のGoogle Chrome本体を `channel: "chrome"` で起動します。ログイン状態はPlaywright専用の永続プロファイル `data/playwright-chrome-profile` に保存されます。普段使っているChromeのDefaultプロファイルは直接使いません。

ChatGPTログイン時にChrome上部へ「サポートされていないコマンドライン フラグ --no-sandbox を使用しています」と表示される場合、ログインやCloudflare認証が失敗しやすくなります。このアプリでは通常のGoogle Chrome + Playwright専用プロファイルを使い、`--no-sandbox` を付けずに起動します。

初回だけ次の手順でログインしてください。

1. PCで `npm run dev` を起動します。
2. 設定画面を開き、`browserMode` が `chrome（通常のGoogle Chrome）` になっていることを確認します。必要に応じて `chromium（Playwright同梱）` へ変更できますが、ChatGPTログイン安定化の推奨は `chrome` です。
3. 工程0〜6のいずれかを実行して、Playwright専用Chromeを起動します。
4. 起動した専用Chrome上でChatGPTへ手動ログインします。
5. ログイン完了後、同じ専用Chromeで工程を再実行します。

2回目以降は `data/playwright-chrome-profile` に保存されたCookie/セッションが再利用されるため、通常は再ログイン不要です。Chromeが見つからない場合はGoogle Chrome本体をインストールするか、設定画面の `browserMode` を `chromium` に切り替えてください。

## 2段階送信方式

各工程はデフォルトで2段階送信です。

1. 各工程の専用ChatGPTプロジェクトを開く
2. 新規チャットで「このチャットでは以下のプロンプトに従い、作業を実行してください。」という初期化メッセージと工程プロンプト全文を送信する
3. ChatGPTから確認返答を受け取る
4. その後、3行判定コードまたはnote記事を1件ずつ送信する
5. 出力をUIに保存する

一括実行では、同じ工程内で初期化済みチャットを使い、1銘柄ごとにプロンプト全文を再送しません。工程が変わる場合は別プロジェクト・別新規チャットを使います。

## 使い方

### 工程0: 買い目判定

トップ画面で固定コマンドを押すか、カスタム欄に `ランダム半導体　実行` / `メタプラネット 実行` のように入力します。旧形式の `ランダム実行` は送信されません。

固定コマンド:

- ランダム　実行
- ランダムヨシ　実行
- ランダム高配当　実行
- ランダム期待先行　実行
- ランダムテーマ株　実行
- ランダムモメンタム　実行
- ランダム待て　実行

### 手動取り込み

Playwrightが失敗しても運用継続できるよう、トップ画面の大きなテキストエリアへ3行判定コードを貼り付けて「解析してバッチ作成」を押せます。v3の4判定だけを取り込み、旧形式の `待て╰( Ｕ ・ω・)` や判定保留はログに警告として残します。

### バッチ詳細

バッチ詳細では工程別の未生成分一括生成、全件再生成、銘柄ごとの個別再生成ができます。各成果物タブにはテキストエリア、コピー、保存、再生成、クリアがあります。日本語Xポストは本ポストのみ保存します。

工程1〜3は3行判定コードから実行します。工程4〜6はnote記事から実行し、画像生成は行わず英語の画像生成指示書のみ保存します。

## プロンプトテンプレート

プロンプト画面で7工程すべてのテンプレートを編集・保存できます。保存先は `data/promptTemplates.json` で、初期ファイルは `prompts/*.txt` にも配置しています。保存後は次回実行の2段階送信初期化メッセージに反映されます。

## 保存・エクスポート/インポート

PC側ローカルJSONに保存します。

- `data/batches.json`
- `data/settings.json`
- `data/promptTemplates.json`

設定/プロンプト画面から、全体・バッチ・設定・プロンプトJSONをエクスポート/インポートできます。

## よくあるエラーと対処法

- **URL未設定**: 設定画面で工程別ChatGPTプロジェクトURLまたは `defaultProjectUrl` を登録してください。
- **ChatGPTにログインしていません**: PC側のPlaywrightブラウザでChatGPTへログインしてください。
- **新規チャット開始に失敗**: ChatGPTのUI変更でボタンが見つからない可能性があります。手動取り込み・手動保存で運用継続し、セレクタを調整してください。
- **3行判定コードがありません**: 工程1〜3は `rawJudgmentText` が必要です。工程0または手動取り込みを先に実行してください。
- **note記事がありません**: 工程4〜6はnote記事が必要です。工程3を先に実行してください。
- **npm installが失敗**: ネットワークや社内レジストリ制限を確認してください。
