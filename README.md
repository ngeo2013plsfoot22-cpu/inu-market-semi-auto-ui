# イヌ式市場|手動コピペ支援UI

Vite/Reactで動く、フロントエンド単体の静的Webアプリです。GitHub Pagesなどで `dist/` を公開すれば、PCのローカルサーバーを起動しなくても、スマホやPCのブラウザからURLを開くだけで使えます。

## このUIでやること・やらないこと

- このUIはChatGPT自動操作をしません。
- OpenAI API、サーバー保存、ブラウザ操作ツールは使いません。
- 工程チャットを開き、入力文をコピーし、ChatGPTの出力をUIへ貼り戻すための手動コピペ支援UIです。
- データは端末のブラウザ内ストレージに保存されます。
- PCとスマホは自動同期しません。
- 別端末へ移す場合はJSONエクスポート/インポートを使います。
- 同じバッチを複数端末で同時編集しないでください。
- ローカル開発時のみ `npm run dev` を使います。本番利用では公開URLを開くだけです。

## セットアップ

```bash
npm install
npm run build
```

ビルド成果物はリポジトリ直下の `dist/` に出力されます。`dist/` は静的ホスティングできます。

ローカル開発時だけ以下を使います。

```bash
npm run dev
```

ビルド結果をローカルで確認する場合だけ以下を使います。

```bash
npm run preview
```

## GitHub Pagesで公開する手順

このリポジトリ名は `inu-market-semi-auto-ui` なので、Viteの `base` は `/inu-market-semi-auto-ui/` に設定しています。公開URLは以下です。

```text
https://ngeo2013plsfoot22-cpu.github.io/inu-market-semi-auto-ui/
```

GitHub Pagesの公開元は **GitHub Actions** を使います。`main` ブランチへpushすると、`.github/workflows/deploy.yml` が自動で以下を実行します。

1. Node.js 20をセットアップします。
2. `npm ci` で依存関係をインストールします。
3. `npm run build` で静的ファイルをビルドします。
4. 生成された `dist/` をGitHub Pages artifactとしてアップロードします。
5. GitHub Pagesへデプロイします。

初回だけGitHubリポジトリの **Settings > Pages > Build and deployment > Source** を **GitHub Actions** に設定してください。その後は `main` ブランチへのpush、またはActions画面からの手動実行（`workflow_dispatch`）で公開できます。

公開後はPCで `npm run dev` を起動しなくても、スマホやPCのブラウザで上記URLを開くだけでUIを使えます。

## 保存と端末移行

実データは、公開した静的Webアプリを開いた各ブラウザの localStorage（ブラウザ内保存）または、画面から読み込むJSONインポートで管理します。`data/settings.json`、`data/promptTemplates.json`、`data/batches.json` はチャットURL・プロンプト・銘柄作業履歴などのprivate情報を含む可能性があるため、GitHubへコミットしないでください。リポジトリには構造確認用の `data/*.example.json` だけを置きます。

保存対象はすべてブラウザ内に保存されます。

- `batches`
- 各バッチ内の `stocks`
- `settings`
- `promptTemplates` / `templates`
- `favoriteCommands`
- project/chat URLs
- `postStatus` 相当の工程別保存状態（各銘柄の `statusByStep`）

設定画面またはプロンプト管理画面の「JSONエクスポート/インポート」から、全データを書き出し・読み込みできます。

インポート時に選べる項目：

- 既存データに追加
- 既存データを上書き
- 同じ `batchId` がある場合：上書き / スキップ / 複製

PCとスマホ間で作業を移す場合は、作業元で全体JSONをエクスポートし、作業先でインポートしてください。自動同期はしないため、同じバッチを複数端末で同時編集しないでください。

## 工程チャットURL設定

設定画面で以下の固定チャットURLを保存できます。

- `step0ChatUrl`: イヌ式市場|買い目判定
- `step1ChatUrl`: イヌ式市場|X記事作成
- `step2ChatUrl`: イヌ式市場|X英語ポスト作成
- `step3ChatUrl`: イヌ式市場|note記事作成
- `step4ChatUrl`: イヌ式市場|X日本語ポスト作成
- `step5ChatUrl`: イヌ式市場|note画像指示書
- `step6ChatUrl`: イヌ式市場|X画像指示書

URLが未設定の工程で「工程チャットを開く」を押すと、設定画面でURL登録を促します。

## プロンプト管理

プロンプト管理画面では、工程0〜6のプロンプト全文を保管・編集・保存・コピーできます。通常作業ではプロンプト全文を毎回貼らず、プロンプト設置済みの工程チャットを開いて入力文だけをコピーします。

各プロンプトには以下の補助コピーがあります。

- このプロンプトをコピー
- 初期化文をコピー
- UI貼り戻し用出力ルール付きでコピー

## 工程0：実行コードボタン

工程0画面には以下のセクションがあります。

- 基本
- セクター・テーマ
- 待て系
- お気に入り
- カスタム

ボタンを押すと実行コードをクリップボードへコピーします。カスタム実行コードは、お気に入りへ追加・削除・並び替え・名前変更できます。

## 貼り戻しとコードブロック抽出

工程0の3行判定取り込み欄と、各銘柄カードの出力貼り戻し欄に「コードブロックだけ抽出」ボタンがあります。ChatGPTが ``` で囲んだ出力を返した場合でも、中身だけを抽出して保存できます。
